# Cpp-UFMT

Repositório com os exercícios de C++ que venho resolvendo durante a disciplina de **Programação II** (UFMT — Campus Universitário do Araguaia) e nos meus estudos por conta própria da linguagem.

## Sobre

Este repositório serve como registro da minha evolução aprendendo C++: dos primeiros programas com `cout`/`cin` até tópicos mais avançados como estruturas de controle, tipos estruturados e alocação dinâmica de memória.

## Exercícios

### Aula 1 — Entrada e Saída Básica (cout/cin)

| Arquivo | Descrição |
|---|---|
| `Print.cpp` | Imprime uma frase simples na tela |
| `Cadastro_em_duas_linhas.c++` | Lê nome e cidade com `getline` e exibe cada um em uma linha |
| `Dobro_de_um_numero.cpp` | Lê um número inteiro e exibe o dobro |
| `Triplo_de_um_numero.cpp` | Lê um número inteiro e exibe o triplo |
| `Soma.cpp` | Lê dois números e exibe a soma |
| `Diferença.cpp` | Lê dois números e exibe a subtração entre eles |
| `Multiplicação.cpp` | Lê dois números e exibe o produto |

### Aula 3 — Estruturas Condicionais e Laços

| Arquivo | Descrição |
|---|---|
| `Ano_copa.cpp` | Verifica se um ano digitado é ano de Copa do Mundo |
| `Exercicio_Fibonacci.cpp` | Exibe a sequência de Fibonacci até um número informado |
| `Exercicio_faixa_etaria.cpp` | Classifica uma idade em faixas etárias (bebê, criança, adolescente, adulto, idoso) |
| `Exercicio_Reajuste.cpp` | Calcula reajuste salarial por faixa de renda |
| `Exercicio_Fatorial.cpp` | Calcula o fatorial de um número inteiro |

> A lista vai crescer conforme eu avanço na disciplina — atualizo essa tabela a cada novo exercício.

### Anotações

| Arquivo | Descrição |
|---|---|
| `Tipos_de_dados_primitivos.cpp` | Notas sobre os tipos primitivos do C++ (char, int, float, double, wchar_t, bool) |

## Como compilar e executar

No Linux (Mint/Ubuntu/Debian):

```bash
# instalar o compilador, se ainda não tiver
sudo apt install build-essential

# compilar
g++ nome_do_arquivo.cpp -o nome_do_arquivo

# executar
./nome_do_arquivo
```
